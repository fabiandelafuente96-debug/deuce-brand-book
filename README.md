# deuce brand book

The visual brand for **deuce**, the racquet-sports community app (working name). Logo, colour, typography, voice, imagery, motion, and how the brand shows up in the app, on social, in merch and out of home.

**Your court. Your crew.**

## Viewing

The site is a single static page (`index.html`) served with GitHub Pages. Open `index.html` locally, or visit the Pages URL in this repo's About panel.

## Contents

- `index.html`: the brand book
- `images/`: photography (AI-generated with Gemini) and app screens
- `illustrations/`: system-message illustrations, light and dark
- `favicon.svg`, `og.jpg`: browser icon and link-preview image

## Notes

- The name, handles (@playdeuce) and domain (playdeuce.app) are not final.
- Search engines are asked not to index this site (`robots.txt` and a `noindex` meta tag). Anyone with the link can still view it.
